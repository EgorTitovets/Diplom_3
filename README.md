# Diplom_3 "Stellar Burgers — Автотесты"

## 📌 Описание  
Автоматизированное тестирование веб-приложения **Stellar Burgers** с использованием **Selenium WebDriver** и **pytest**.  
Тесты написаны с применением **Page Object Model**.  

## 🛠 Используемые технологии  
- Python  
- Selenium  
- Pytest  
- Allure  
- Chrome / Firefox

🔍 Описание тестов

📌 Восстановление пароля

✅ Переход на страницу восстановления пароля
✅ Ввод почты и клик по кнопке «Восстановить»
✅ Проверка, что поле пароля активируется при нажатии «показать/скрыть»

📌 Личный кабинет

✅ Переход в личный кабинет
✅ Переход в раздел «История заказов»
✅ Выход из аккаунта

📌 Основной функционал

✅ Переход по клику на «Конструктор»
✅ Переход по клику на «Лента заказов»
✅ Открытие всплывающего окна с деталями ингредиента
✅ Закрытие всплывающего окна
✅ Увеличение счётчика ингредиента при добавлении
✅ Оформление заказа залогиненным пользователем

📌 Лента заказов

✅ Открытие всплывающего окна с деталями заказа
✅ Проверка отображения заказов пользователя в «Истории заказов»
✅ Увеличение счётчика «Выполнено за всё время» после создания заказа
✅ Увеличение счётчика «Выполнено за сегодня» после создания заказа
✅ Проверка, что заказ появляется в разделе «В работе» после оформления
